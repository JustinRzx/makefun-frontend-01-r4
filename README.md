Radar is a read-only client for make.fun: a two-pane bounty board with live pots, entry fees and
time left beside a filled detail pane, a bounty page with a fee-share rewards table and its current
top 5, a ranked leaderboard, and public builder profiles. Plain ES modules and hand-written CSS,
no build step, ETag-revalidated reads, light and dark themes.

## Run it

```sh
node serve.ts --port 8080
```

Open http://localhost:8080. It reads https://make.fun/api and needs nothing else.
